# Fiche Play Store (FR)

## Nom de l'application
Tempo Tracker Élec

## Description courte
Suivi conso et coûts Tempo avec import CSV Linky en local.

## Description complète
Tempo Tracker Élec vous aide à suivre votre consommation électrique et vos coûts simplement.

Importez vos exports Linky (CSV), puis visualisez vos dépenses à l'échelle:
- journalière
- mensuelle
- annuelle

L'application calcule:
- le coût énergie selon l'option Tempo (couleurs et plages HP/HC)
- l'impact de l'abonnement annuel TTC via un prorata journalier
- le total TTC par jour et par période

Fonctions principales:
- import CSV Linky depuis votre appareil
- tableaux de bord de suivi (KPI, graphiques, historique)
- filtrage par année et mois
- fonctionnement local, sans envoi automatique de vos données personnelles vers un serveur

Les données d'usage restent sur l'appareil de l'utilisateur.
